# September–October 2026 Big Bear event sweep

Research completed September 1, 2026. This is an implementation handoff, not a second event source. Every calendar claim below was checked against an organizer, venue, government, destination, or local Chamber page. Visit Big Bear's complete September/October event index was reviewed page by page; organizer and venue calendars won when recurring directory data disagreed.

## Curation rule used

- Free first.
- $1–20: include readily when relevant.
- $20–40: include when distinctive.
- $40–50: selective.
- More than $50: normally exclude.
- Strong interests: free concerts and car shows; karaoke, trivia, line dancing, country/punk/metal; astronomy, wildlife, plants, geology/science, environmental volunteering; weird local or mountain-town nights.
- Keep transportation and service schedules outside the events feed.
- `Skyline at Sundown` is a permanent exclusion, not a one-date skip.

Primary sweep surface: <https://www.bigbear.com/events/>.
